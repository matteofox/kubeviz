                    *** KUBEVIZ PYTHON PORT: NOTES ***

The Python version reproduces the IDL program (V2.2) routine by routine. This
file lists what differs for the user. The IDL instructions (Help -> Instructions)
remain valid for everything else.

** Starting kubeviz **

  kubeviz cube.fits --redshift 0.85 --lineset 1        interactive session
  kubeviz cube.fits --redshift 0.85 --lineset 1 --batch --fit-all-lines
  kubeviz session.kvz                                  reopen a saved session
  kubeviz idl_session.sav                              import an IDL session (best effort)
  kubeviz --demo                                       synthetic demo cube
  kubeviz --help                                       all options

Every IDL keyword is a command line flag with the same name (dashes instead of
underscores are accepted): --noisefile, --ext, --noise-ext, --trim, --fluxfac,
--smooth, --specsmooth, --transpose, --vacuum, --logarithmic, --waveunit,
--redshift, --do-mc-errors, --bootstrap, --nmontecarlo, --plot-mc-pdf,
--save-mc-pdf, --use-mc-noise, --lineset, --debug, --mask-sn-thresh,
--mask-maxvelerr, --mom-thresh, --spmask, --instr, --band, --batch,
--fit-all-lines, --fix-ratios, --resfile, --fittype, --outdir, --logfile,
--fitpars, --momwindowfile, --gaussinitfile, --scalenoiseerr.

** Windows **

One main window. The spaxel viewer is the central panel: a toolbar (cube, image
mode, intensity scaling, colour table, invert, cursor mode), the image with an
interactive colour bar (drag the bar handles to set the cuts; the bar is labelled
with the displayed quantity), the wavelength slider and an info row (spaxel, value, RA/Dec, mask, smoothing; the
position in the original cube appears only for a trimmed cube). All text is 12 pt.
The other panels are dock widgets in the right column: Spectrum, Spectral zoom
and Line fitting. The last one holds the Fit results table (one row per line;
the rows of the second component appear with the "2nd component rows" switch,
automatically when a second component is fitted), the Fit setup, Options and
Status groups, which fold away, and the grid of action buttons (current
spaxel/mask on the top row, all spaxels/masks below). Docks can be dragged to
other positions, floated or closed (reopen with Options -> Show linefit window /
Toggle Zoom); every start uses the default layout, sized to about 92 % of the
screen (the fitting unit and fit type are toggled with the SPAXEL / GAUSS buttons in
the Fit results header; on displays below 900 px the Fit setup group starts folded). Spectra are drawn as
steps (edges half way between wavelengths), fits as lines.
The status bar shows the last message. During FIT ALL / FIT ADJ ALL the
Status row of the Line fitting panel shows a progress bar and an Interrupt
button, and the crosshair follows the spaxels being fitted. Both loops use forked
worker processes (--nproc N; default all cores but one, at most 8). FIT ALL gives
exactly the sequential results; in FIT ADJ ALL the spaxels of one pass start from
the neighbour solutions at the beginning of the pass (--nproc 1 for the IDL order).

** Mouse in the spaxel viewer **

  left click / drag       move the crosshair, or paint / erase the spaxel mask
  right drag              brightness and contrast (as in IDL)
  mouse wheel             zoom in / out around the cursor (continuous)
  middle drag             pan;  shift + left drag also pans
  Reset view button       show the whole field again

The integer zoom factor and the edge-click navigation of the IDL version are
gone: zoom and pan are continuous.

** Spectrum and zoom panels **

Both plots are interactive: wheel zooms, drag pans, right drag zooms a box,
"A" (bottom left of the plot) or a double click restores the automatic range.
Left click sets the current wavelength. The zoom panel shows the pixel index
on the top axis and the wavelength on the bottom axis. The fitted components
are drawn in red (1st component / moments), blue (2nd component), the total
model in dashed green; dotted blue lines mark the continuum windows.

** Keyboard shortcuts **

Identical to the IDL version (Help -> Keyboard shortcuts). "," and "." also
step through wavelength planes (in addition to "<" and ">").

** Files **

  Results      *_res.fits and *_noflag.fits with the same plane layout and
               header keywords as the IDL version; files can be exchanged.
  Sessions     .kvz files (compressed Python pickles). IDL .sav sessions can be
               opened read-only (File -> Load Session, or from the command
               line); Monte Carlo cubes are regenerated on demand.
  Images       "Save Image as PNG" replaces "Save Image as EPS".
  MC plots     PNG files instead of EPS.

Nothing is saved when you quit: use File -> Save Session when you want to keep the
state (the IDL version wrote lastsession.sav on exit). Sessions saved from the GUI
or in batch mode do not store the Monte Carlo realisations; they are recreated when the session is
reopened (MC1/2/3 use fixed random seeds, bootstrap cubes are re-read from the
original file).

** Numerical differences worth knowing **

The fitter is scipy's bounded least-squares instead of MPFIT; results agree to
numerical precision for well-behaved fits. A start value outside the user
limits is clipped instead of aborting the fit. Random numbers are reproducible
but not identical to IDL. The full list of deliberate differences is in
PORTING.md in the repository.
